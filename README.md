# Student Portfolio

A responsive React + Vite portfolio for Bharath Kumar S, focused on his frontend development transition, internship, web and mechanical engineering projects, education, NSDC certifications, and transferable experience.

Portfolio content is based on Bharath's resume and details he provided. The Smart India Hackathon project is marked in progress, and no implementation claims are made beyond the information confirmed so far.

## Getting started

Install dependencies with `npm install`, then start the local development server with `npm run dev`.

## Production build

Run `npm run build` to generate the production site in `dist/`. Use `npm run preview` to preview that build locally.

## Deploy with GitHub Pages

The workflow in `.github/workflows/deploy.yml` builds and deploys the site when changes are pushed to `main`. Create or connect a GitHub repository, push this project to its `main` branch, then open the repository's **Settings → Pages** and choose **GitHub Actions** as the build and deployment source. After the workflow completes, GitHub Pages will show the live URL in the repository settings and the workflow run.

## Personalize before publishing

- Update the `profile`, `skills`, `projects`, `education`, and `certifications` data near the top of `src/App.jsx` as experience changes.
- Add project-specific repository/demo links when they are available. The current GitHub link points to Bharath's profile.
- The Resume button downloads the current resume PDF, which reflects Bharath's mechanical engineering background. Replace it with an IT-focused version when available.
- Update the page title and description in `index.html`.
- Check every link and the mobile layout before sharing or deploying.

No profile photo or unconfirmed LinkedIn link is included.
